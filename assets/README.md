# Assets Placeholder

The following image files are required by app.json before you can run the app.
Replace each placeholder with a real PNG image at the correct size.

| File | Size | Purpose |
|---|---|---|
| `icon.png` | 1024×1024 px | App icon |
| `splash.png` | 1284×2778 px | Splash/loading screen |
| `adaptive-icon.png` | 1024×1024 px | Android adaptive icon foreground |

## Quick way to generate placeholders:
You can use any solid-color 1024×1024 PNG for testing.
Or use Expo's asset generation tool after running `npm install`:

```bash
npx expo generate-assets
```

Or download free placeholder images from:
- https://placehold.co/1024x1024/4A2C2A/white?text=☕
